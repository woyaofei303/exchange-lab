# ADR-007：逐仓与全仓使用同一权威风险仓储

状态：Accepted

## 决策

逐仓记录 position-specific margin；全仓按用户聚合可用余额、各仓位保证金和未实现盈亏。所有调整在 PostgreSQL Serializable 事务中更新余额、账本/事实、风险版本和审计。

## 原因与代价

共享仓储让两种模式复用仓位与价格事实并维持一致的不变量。代价是全仓计算/锁范围较大；v1 优先正确性，没有做大规模风险分片。

## 失败与回滚

任何校验或写入失败整体回滚。存在开放仓位或处理中强平时拒绝危险模式切换。回滚二进制前先确认新旧风险版本与 schema 兼容。
