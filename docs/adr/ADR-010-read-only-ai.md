# ADR-010：AI 与 MCP 永久位于只读解释边界

状态：Accepted

## 决策

AI 风险助手只能调用用户授权的只读工具，输出必须符合结构化 schema 并引用工具证据。MCP 工具不提供下单、取消、保证金、资金或管理写入；所有调用记录脱敏审计。

## 原因与代价

模型输出是非确定性的，不能成为账务或风控真值。只读边界降低 prompt injection、幻觉和越权的影响，但 AI 不能替用户执行交易，模型不可用时只能给确定性 fallback。

## 失败与回滚

超时、schema 失败、证据缺失或 provider 不可用时返回固定降级结果，不影响核心交易 API。可关闭 AI/MCP 进程而不迁移或删除交易数据；审计事实保留。
