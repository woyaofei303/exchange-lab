# exchange-lab v1.0 产品范围

`exchange-lab` 是教学级、纯模拟、USDT 本位、单向持仓的永续合约平台。它用于学习 Go 全栈、交易领域、事件驱动、数据库事务、AI 只读工具和部署恢复；不接真实资金，不提供投资建议，也不等价于真实交易所生产风控。

v1.0 包含：BTCUSDT-PERP、限价撮合、账户/账本、逐仓与教学级全仓、仓位/PnL、指数价/标记价、资金费、强平、保险基金、简化 ADL、reduce-only 条件单、React 终端、只读 AI/MCP、监控、备份和回滚包。

v1.0 不包含：真实托管/充提、法币、现货、双向持仓、多资产抵押、组合保证金、完整订单类型、真实多交易所现货源、生产级撮合集群、合规/KYC、真实资金清算和自动交易 AI。边界详情见 `known-limitations.md`。

核心不变量：

- 金额、价格、数量、保证金、PnL 只用整数 atoms + scale 作为真值。
- 账本交易内所有分录之和为 0；重复业务事件不产生第二次资金副作用。
- 风控与强平只读取带 freshness 的标记价格，不直接使用最新成交价。
- AI 只能读取服务端已经计算的事实，不能下单、撤单、改杠杆、调保证金或改余额。
- PostgreSQL 是交易真值；Redis 是可重建缓存/短期安全状态；NATS JetStream 传递可重放事实。
