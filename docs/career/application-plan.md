# 12 周求职落地计划

## 第 1–2 周：材料与演示

- 把 `resume-project.md` 按原简历模板加入项目经历，不改变模板结构。
- 录制 8–12 分钟本地演示，GitHub README 保留启动、架构、验证和限制。
- 准备 60 秒/5 分钟两个版本项目介绍。

## 第 3–6 周：Go 与系统设计强化

- 每周重写一个核心：fixed math、Outbox、撮合、风险；不看答案先写测试。
- 每周做两次 Go 并发/数据库题和一次系统设计白板。
- 用真实 bug（JSON contract 导致仓位事件 parking、funding 单边余数）准备 STAR。

## 第 7–10 周：定向投递

- 目标岗位：Go 后端/全栈、交易系统、金融科技基础设施、AI 工程化。
- 每周 15–20 个高匹配岗位；记录岗位、技能缺口、投递、面试阶段和复盘。
- 前端经历作为优势，重点表达“能交付端到端交易流程”，不贬低既有经验。

## 第 11–12 周：复盘与补洞

- 汇总被问倒的问题，优先补 Go runtime/concurrency、PostgreSQL lock/index、消息幂等、风控公式和部署恢复。
- 只增加能被测试/文档证明的功能；不为简历临时包装生产规模。
- 每轮面试后 24 小时内更新问答和一个最小代码实验。
